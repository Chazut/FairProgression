# Fair Progression 1.1.0 — SPT 4.1.6

- Updated from the SPT 4.0.13 release to support SPT 4.1.6.
- Keeps quest XP balanced around vanilla progression when using quest mods.
- Existing Fair Progression settings remain compatible.

**Installation:** Extract the ZIP into your SPT game folder. Back up your config first and restore it after updating to keep your settings.

Still on SPT 4.0.13? Keep using Fair Progression 1.0.0.
