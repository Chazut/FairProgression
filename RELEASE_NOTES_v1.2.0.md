# Fair Progression 1.2.0

## Features

- Choose how much extra XP to keep from quest mods, from 0% to 100%.
- Preview rewards in the new ORBIT-themed editor in SPT's web menu. Compare XP by level bracket, then pick a trader to see what changes for each quest.

## Upgrading

Keep your existing `config/config.jsonc` when extracting the ZIP. Saved settings take effect after a server restart.
